Tạo dữ liệu cho trang gợi ý chào hàng

Chọn file Excel, đặt mật khẩu, tải về data.enc.json. Mọi xử lý diễn ra ngay trên máy bạn, file Excel không bị gửi đi đâu.

Dùng mật khẩu dài và chia sẻ riêng cho nhân viên. Mật khẩu này sẽ được nhập khi mở trang gợi ý chào hàng.
  1. Tải file data.enc.json vừa tạo lên GitHub, thay file cũ trong repo.
  2. Chờ 1 đến 3 phút, trang web sẽ có số liệu mới.
